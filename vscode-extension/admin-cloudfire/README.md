## 🛠️ Relevant Technologies & Key Libraries

In compliance with project architecture rules, here are the key technologies and libraries powering this component:

- **WPipe (`wpipe>=2.5.0`)**: The core workflow orchestration engine powering `Pipeline`, `@step`, `@to_obj`, and timeout/retry management.
- **Pydantic (`pydantic>=2.0.0`)**: Strongly-typed Data Transfer Objects (`AdminPipelineContext`, `LicenseDTO`, `ActivationDTO`) in `dto/`.
- **Streamlit (`streamlit>=1.39.0`)**: Interactive web dashboard framework providing dark-mode tables, reactive forms, and real-time KPI metrics.
- **Pandas (`pandas>=2.0.0`)**: Tabular data manipulation for displaying filtered licenses, activations, and audit logs.
- **Cloudflare D1 & REST API**: Serverless distributed SQLite database deployed at Cloudflare Edge, queried with microsecond latencies.
- **Cloudflare R2**: Zero-egress fee object storage serving `wpipe-engine` compiled binary releases.
- **Docker & Docker Compose**: Containerized multi-service deployment with integrated healthcheck on port `8501`.
- **Pytest & Pytest-Cov**: Automated unit testing with Docker runner script and code coverage analysis.

## 🚀 Running with Docker Compose

### 1. Environment Setup

Copy `.env.example` to `.env` and fill in your Cloudflare credentials:

```bash
cp .env.example .env
```

Key variables:
- `CLOUDFLARE_ACCOUNT_ID`: Your Cloudflare account ID (`e3a420c454b6c6ca891b31aea00ac53f`).
- `CLOUDFLARE_D1_DATABASE_ID`: D1 database ID (`44bf0372-587d-446d-84c3-1153c4183b99`).
- `CLOUDFLARE_API_TOKEN`: Cloudflare API Token with `D1:Edit` permissions.
- `ADMIN_PASSWORD`: Access gate password (default: `wisrovi2026`).
- `API_BASE_URL`: Cloudflare Worker API URL (`https://api.wisrovi.dev`).

### 2. Start the Service

```bash
docker compose up -d --build
```

Access the admin dashboard at:  
👉 **`http://localhost:8501`**

### 3. Stop the Service

```bash
docker compose down
```
